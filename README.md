# ANALOG-X

Mission-specific planetary analog reconnaissance prototype for NASA Space Apps Challenge 2026.

Team: X Æ A-Xii  
Participant: Muhammad Usman Mughal

The project investigates which aspects of the Koh-i-Sultan volcanic field in Chagai, Pakistan, may inform field-geology methods and robotic geological reconnaissance for Martian volcanic terrain represented by the Syrtis Major quadrangle.

Scientific integrity: this is a reconnaissance prototype. It does not claim planetary equivalence or a calculated analog score. Raw MOLA and NASADEM/SRTM rasters have not yet been processed. NASA GIBS imagery is a visual browse layer only. SUPARCO data access and licensing for Chagai have not been verified.

Open `index.html` for the app. See `docs/` for methodology, sources, limitations, SI disclosure and NASA submission copy. See `science/` for reproducible processing scripts.
