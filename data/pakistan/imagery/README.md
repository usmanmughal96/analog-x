# Sentinel-2 spectral-context screens

Products generated by scripts/process_sentinel_evidence.py from Copernicus Sentinel-2 L2A scenes hosted by Microsoft Planetary Computer.

- 20 m common analysis grid; 10 m bands were resampled to B11's 20 m support.
- Koh-i-Sultan: BSI, NDVI, SWIR1/SWIR2 and red/blue reflectance ratios are spectral context only; not mineral identification.
- Hispar Glacier: NDSI and SCL class-11 are screening descriptors; not a validated glacier outline or mass-balance estimate.
- Clouds/shadows/no-data classes are masked. Scene time, tile, cloud metadata, CRS and valid-pixel counts are preserved in each profile.

Contains modified Copernicus Sentinel data. See docs/DATA_SOURCES.md for source attribution and limitations.
