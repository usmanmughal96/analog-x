# Pakistan analog evidence catalogue

Generated by scripts/fetch_public_evidence.py.

- Microsoft Planetary Computer: anonymous STAC search for Sentinel-2 L2A scene metadata. This is scene discovery, not raster ingestion.
- EvK2CNR: metadata record fetch attempted for the Pakistan Glacier Inventory; product access and reuse terms are recorded separately.
- Sentinel-2 assets require a short-lived SAS token for Azure data access; no account is required for public STAC metadata or token issuance.

Do not treat scene metadata as mineralogy, field validation, or a planetary similarity score.
