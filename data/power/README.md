# NASA POWER snapshots

Server-side snapshots fetched by the GitHub Actions workflow.
The public app reads these same-origin JSON files rather than making a browser cross-origin NASA request.

NASA POWER: https://power.larc.nasa.gov/
API docs: https://power.larc.nasa.gov/docs/services/api/temporal/climatology/
Community/parameter availability: https://power.larc.nasa.gov/docs/methodology/communities/

Null values mean missing/unavailable. They are never converted into matches.
